Upload & Analyse an RFP

Accepts tender documents, EOIs or corrigenda in PDF, Word (.docx) or plain text — one file, or several at once (e.g. the main RFP plus a separate BOQ or corrigendum). Everything is parsed on your device — no file leaves the browser.

⇪

Drag & drop one or more files here

or click to browse · PDF, DOCX, TXT · select multiple files to analyse them together

Reading document…
How this works — Drishti (1) pulls out any Annexure / Appendix / Schedule / Proforma / BOQ formats the RFP itself contains, so you can download the blank ones straight into Word instead of retyping them, and (2) scans the rest of the text for known tender patterns (turnover, manpower, certifications, GPU/storage/network figures, RPO/RTO, SLA % etc.) and cross-checks each against your ESDS Capability Library. Upload more than one file — e.g. the main RFP plus a separate corrigendum or BOQ — and they're combined into a single report; each detected annexure notes which file it came from. This is a fast first pass, not a legal reading of the tender — always verify critical clauses (dates, EMD, evaluation weightage) and complex tables against the source PDF before submission.

ESDS Certificate Templates

These are ESDS-authored letters (turnover, manpower, GPU/compute self-certifications etc.) — use them when the RFP asks for a self-declaration but doesn't supply its own format. If the RFP already provides a blank annexure/BOQ format, get that instead from Analysis Report → "Annexures found in this RFP" — no retyping needed.
